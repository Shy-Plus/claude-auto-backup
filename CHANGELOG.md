# Changelog

## [1.0.0] - 2026-03-31

### Features
- Auto-backup every 15 minutes + on conversation switch
- Direct local file writing via File System Access API
- Persistent directory handle (IndexedDB)
- Full Markdown export with metadata table
- Batch backup all conversations (up to 80)
- Glassmorphism floating UI with status indicator
- Dark mode auto-detection
- Tampermonkey menu commands
- Backup index tracking via GM storage
